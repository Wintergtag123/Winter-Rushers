# ❄️ Winter Rushers — Mobile Edition

An original, mobile-friendly browser tag game. Play on iPad/iPhone Safari or desktop browsers.

## Play
Open `index.html` in a browser or publish the repository with GitHub Pages.

- **Mobile:** left touch joystick to move, JUMP to hop over obstacles.
- **Desktop:** WASD/arrow keys to move, Space to jump.
- Chase and tag the orange runners in 60 seconds.

## GitHub Pages
In your repository: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. Your site will become available at `https://YOUR_USERNAME.github.io/YOUR_REPO/` after publishing.

This is a 2D prototype; it is not a full 3D VR port. It uses original placeholder art and no Gorilla Tag assets.
